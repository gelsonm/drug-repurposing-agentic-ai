# drug-repurposing-agentic-ai

What is Drug Repurposing with Agentic AI?
Drug repurposing (or drug repositioning or drug reprofiling) identifies new therapeutic uses for existing approved drugs, bypassing costly early-stage development. Traditional timelines of 10-15 years and $2B+ are compressed to months. Agentic AI systems — LLMs orchestrating specialized tools autonomously — are now driving this process at scale.
